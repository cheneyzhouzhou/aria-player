# Aria v114

这一版把毛玻璃主题的透明度做成用户可调的**两端极值**，补齐了 macOS 的系统级中英文本地化，并修好了一批状态栏、导航与设置页的细节。iOS 与 macOS 同步。

## 毛玻璃透明度可调（两端）

- 设置页在毛玻璃主题下、主题色条正下方新增透明度滑动条：**0% 完全不透明 / 50% 原始磨砂观感 / 100% 完全透明**。两端都是真正的极值，而不是「更透一点」。
- **0%**：面板由角色自身的实心底色铺满，背后极光完全不透出；内层卡片保留一档明暗差与描边，层级不会糊成一片。
- **100%**：霜层、背景模糊、顶部高光、描边、阴影全部归零，只剩内容浮在背景上——连播放页弹窗原先保留的模糊下限也一并去掉。
- 对**所有**玻璃面生效：侧栏 / 页面容器 / 悬浮播放条 / 底部导航条，以及播放页的均衡器、音频链、播放列表弹窗。
- 选择会持久保存；纯色与莫兰迪主题完全不受影响（相关参数恒为 1）。

## 系统 UI 语言跟随 App（macOS）

- 打包 `en` / `zh-Hans` 语言资源并声明支持的语言，macOS 的系统菜单、文件夹选择面板、弹窗按钮终于会跟随 App 内选择的语言，不再固定英文。
- 切换语言后**本次会话**的系统 UI 仍是旧语言（AppKit 在进程启动前就缓存了语言解析），下次启动生效；App 会检测到不一致并自愈重启一次，不需要手动退出。
- 顺带修好 iOS 语言设置被强制退出后回退英文的问题。

## 菜单栏（macOS）

- 播放控制拆成两个固定宽度的状态栏项：歌名区与右侧三个控制键。切歌时不再整条左右跳动，也不会再与系统图标短暂重叠。
- 菜单里可以单独关掉歌名项，只保留控制键。

## 设置页与导航

- 精简说明文字：毛玻璃透明度、语言、深浅模式、iOS 的 Apple Music 开关、macOS 的输出模式，标题下方不再挂冗余副标题。
- 导航栏三个功能**整行**都可点击（图标、图标与文字之间的间隙、文字本身、两侧留白），不再只能点图标。
- 切换主题时，导航条与悬浮播放条会立即换成新材质，不必再点一次别的页面才生效。
- 英文文案里「受版权保护」统一为 DRM 表述：`DRM-protected songs will be skipped` / `%d DRM-protected skipped`。

## 体积

iOS 约 2.30 MB；macOS arm64 约 1.5 MB、通用包约 2.6 MB。

## 安装

- **iOS**：用 Sideloadly / AltStore 侧载 `Aria-v114.ipa`（免费 Apple ID 签名 7 天有效，到期重签即可）。
- **macOS**：解压后把 `Aria.app` 拖入「应用程序」；如首次打开被拦截，右键 → 打开。

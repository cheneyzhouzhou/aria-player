# Aria v75

这一版把外观细节和 iOS 的手感逐处对齐了：图标换成一套昼夜双版本，毛玻璃主题的排版不再溢出，iOS 的返回手势和导航层级也修好了。

## 图标

- 全新一套「柯基戴耳机、踩在进度条上」的图标。**浅色模式为褐色，深色模式为雾霭蓝**，iOS 18 及以上会随系统深浅色自动切换。
- 卡通形象放大约 27%（占画布宽度 53.5% → 68.2%），在桌面和资源库里更醒目，四周仍保留均匀留白。
- macOS 图标同步更新，并按系统规范保留 8.5% 外边距与 22.5% 圆角。

## 毛玻璃主题

- 设置页控件不再撑满面板：毛玻璃下卡片左右各内缩 30pt，与搜索页一致；纯色 / 莫兰迪主题保持原样。
- 资料库标题与面板顶部之间补了留白，不再贴着面板上沿。
- 详情页（专辑 / 艺人 / 播放列表）左上返回按钮与面板圆角对齐，上下左右各 18pt。

## iOS 交互

- **详情页支持整页右划返回**。原来只有屏幕左侧 18pt 的窄条能触发，成功率低；现在从页面任意位置右划都可以，上下滚动不受影响。
- 修复「艺人页 → 某张专辑 → 返回」会直接跳回资料库列表的问题。导航改成了真正的栈，返回一次只退一页。

## 布局细节

- 艺人页的 Play / Shuffle 按钮不再被压成竖排单字；空间不足时自动改为「标题在上、按钮在下」。
- 设置页的主题卡片名称、资料库统计胶囊都不再换行；三个统计胶囊高度严格一致。

## 其它（自 v51 以来的累积）

- 新增「莫兰迪」主题：12 组低饱和主色，与毛玻璃并存。
- macOS 新增菜单栏播放器：当前歌曲与播放控制常驻菜单栏。
- 歌词淡出、iOS 弹窗底部溢出修复等一批细节。

## 体积

图标重新着色与量化后压缩率更高，两个包都比之前更小：iOS 2.15 MB、macOS 通用包 2.55 MB。

## 安装

- **iOS**：用 Sideloadly / AltStore 侧载 `Aria-v75.ipa`（免费 Apple ID 签名 7 天有效，到期重签即可）。
- **macOS**：解压后把 `Aria.app` 拖入「应用程序」；如首次打开被拦截，右键 → 打开。

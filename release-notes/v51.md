# Aria v51

本次更新带来全新的「毛玻璃」主题、深浅模式，以及多项 iOS 体验改进。

## 外观
- 新增「纯色 / 毛玻璃」主题切换：
  - 毛玻璃 = aurora 渐变色场 + 白霜玻璃面板（发丝描边、顶部高光、柔和投影）；
  - 背景缓慢流动（尊重系统「减弱动态效果」设置，开启时静止）。
- 新增「跟随系统 / 浅色 / 深色」深浅模式；深色下选色条与色板提供深色系。
- 设置页改为分割式悬浮玻璃卡片；资料库、搜索、设置三页配色统一。

## macOS
- 侧栏与内容为两块独立的圆角悬浮玻璃面板，窗口读起来是清晰的左右两栏。
- 播放页遇到「自身无封面」的歌曲时，使用内置默认封面（含模糊背景），与 iOS 一致。

## iOS
- 专辑 / 艺人 / 播放列表详情页支持**左缘右滑返回**。
- 队列 / 均衡器 / 音频链路弹窗支持**半高与全高**两种高度；半高时背景自动压暗，悬浮卡片观感更协调。
- 修复弹窗底部的内容溢出与浅色带；播放页弹窗底色改为与播放页背景同源的暗色磨砂。
- 播放页配色（播放按钮、进度条、卡通）跟随封面取色，整体更协调。

## 其它
- 输出设备「显示选中」与「实际发声」保持一致（不再出现高亮与实际发声不符）。

## 安装
- **iOS**：用 Sideloadly / AltStore 侧载 `Aria-v51.ipa`（免费 Apple ID 签名 7 天有效，到期重签即可）。
- **macOS**：解压后把 `Aria.app` 拖入「应用程序」；如首次打开被拦截，右键 → 打开。

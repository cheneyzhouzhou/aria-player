# Aria v172

自 v154 以来的新功能与改进，iOS 与 macOS 同步发布。

## iOS 横屏

- iPhone 解锁左/右横屏方向。
- 播放页横屏采用封面在左、歌词在右的分栏布局；顶部按钮和底部进度/播放控件悬浮显示，5 秒不操作自动隐藏，触摸后恢复。
- 其余页面横屏时，资料库 / 播放列表 / 设置改为最左侧竖排导航，内容不再被导航遮挡；悬浮播放条下移至屏幕底边。
- 横竖屏切换加入淡入淡出与轻微缩放过渡。
- 横屏歌词字号加大，封面与歌名同步放大。

## 正在播放定位按钮

- 在「歌曲」「最近添加」「播放列表详情」中播放歌曲时，显示圆形定位按钮，点击滚动到当前曲目。
- 按钮随主题变化：纯色主题为浅色系，毛玻璃主题使用相同的磨砂材质与透明度设置。

## 播放与搜索

- 资料库搜索框支持 Return、「完成」按钮、点击页面与切换标签收起键盘。
- 播放页改为窗口内呈现，横竖屏切换不再闪回上一页。
- 播放列表与均衡器在横屏中显示为左侧面板，打开时自动隐藏播放控件。

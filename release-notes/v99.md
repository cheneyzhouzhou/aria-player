# Aria v99

这一版把播放页的毛玻璃弹窗彻底做成「真玻璃」，补上了 Apple Music 音乐库接入，并修好了一批播放稳定性与 macOS 交互问题。iOS 与 macOS 两端同步。

## 播放页弹窗：终于能透出封面了

- **真因**：系统 `.sheet` 会把呈现它的播放页隔离到另一个视图层级，`UIVisualEffectView` 根本模糊不到背后的专辑封面 —— 之前反复调材质与透明度都只得到一块白板。
- 把均衡器 / 队列 / 音频链三个弹窗改成**播放页内的悬浮卡片**（与悬浮播放条同一视图层级），玻璃才真正透出封面颜色与横条纹。
- 两端统一透明度档位：材质层淡化到 0.55；macOS 改用模糊更完整的材质，iOS 补一点乳白霜抵消系统模糊被削弱的问题。深色模式也走薄材质，不再是一块深色实板。
- 纯色 / 莫兰迪主题下弹窗改为跟随系统深浅并带主题色，修掉了深色面板与刺眼的高饱和状态色。
- 保留下拉关闭手势并加宽顶部触发区；点击弹窗外或收起按钮仍可关闭。

## Apple Music 音乐库（iOS）

- 设置页「音乐文件夹」新增开关：请求媒体库权限，读取「音乐」App 中**无 DRM** 的曲目（自行导入 / 同步 / 已购买），直接播放、不复制音频文件；界面显示可播放数与受保护跳过数。
- 这类曲目走独立的 `AVPlayer` 分支，现有本地文件播放链路零改动。
- **限制**：Apple Music 订阅下载的 FairPlay 曲目系统不提供原始音频，会被跳过；这些曲目上 Aria 的 EQ、独占输出、采样率锁定不可用。

## 播放稳定性与细节

- 修复随机播放时「状态显示播放中、进度条不动」：`AVAudioEngine` 配置变更自停后增加了观察者与看门狗重新拉起。
- 修复切歌时悬浮播放条突然高亮一下：封面缓存未命中时不再清成占位块。
- 修掉设置页上下滑动误划主题颜色条；iOS 资料库补上小搜索框并与搜索页共用状态。
- macOS 播放页按钮点击热区加大；关闭最后一个窗口后可从 Dock 或菜单栏重新唤出界面，音乐继续播放。
- 菜单栏播放条：歌名自适应宽度、右侧三个控制键位置保持固定；短歌名不再出现宽间距。
- 三个构建脚本统一把版本号写入 app，设置页不再永远显示 `1.0`；mac 设置页新增「音乐 App 媒体目录」快捷入口。

## 体积

iOS 约 2.29 MB；macOS arm64 约 1.5 MB、通用包约 2.6 MB。

## 安装

- **iOS**：用 Sideloadly / AltStore 侧载 `Aria-v99.ipa`（免费 Apple ID 签名 7 天有效，到期重签即可）。
- **macOS**：解压后把 `Aria.app` 拖入「应用程序」；如首次打开被拦截，右键 → 打开。
